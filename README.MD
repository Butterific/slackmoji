<div align="center" style="font-size: 36px;">
  <b>SlackMoji<b>
</div>
<div align="center">
  SlackMoji is an all in one Slack bot that simply that takes in text and returns in emoji form (eg apple ---> 🅰️🅿️🅿️𞋎 𝐄) along with other cool commands!
</div>
<br>
<br>
<br>
<div align="center">
The bot has 5 main commands right now including 
</div>
<div align="center">
/emoji-bot-ping - Check bot latency
</div> 
<div align="center">
/emoji-bot-catfact - Get a cat fact
</div>
<div align="center">
/emoji-bot-fire - Show a fire emoji
</div>
<div align="center">
/emoji-bot-help - Show this help message
</div>
<div align="center">
/emoji-bot-covert - Returns the text in emoji form
</div>
<div align="center">
/emoji-bot-about - Show information about the bot
</div>

<div align="center">
Setup
</div>
<div align="center">
First run npm init -y
</div>
<div align="center">
Then run npm install
</div>
<div align="center">
Then run node index.js and you should be good!
</div>
<div align="center">
make sure to add your envs to the .env file
SLACK_BOT_TOKEN and SLACK_APP_TOKEN
</div>

# SlackMoji

A Slack bot designed to help you mess around and have fun with emojis!

## Quick Start
Simple quick start guide to help you setup the bot!

### Requirements
 - A Slack bot with socket mode enabled and following Bot Token Scopes: `app_mentions:read`, `channels:read`, `chat:write`
 - Node.js/NPM

### Prerequisites
Make sure you have a .env with the following:
```env
SLACK_BOT_TOKEN=your_slack_bot_token
SLACK_APP_TOKEN=your_slack_app_token
```
